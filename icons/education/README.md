## Cornell web guidelines (summary)

- Use the **simple seal** only between **73px and 120px** tall on web.
- Below that size, use the **reduced wordmark** instead of the seal.
- Do not crop, screen, watermark, or recreate the seal artwork.
- Leave clear space around the mark (≈¼ the seal diameter).
- Display the Cornell mark **once** on the homepage.

Replace files here whenever brand centers publish updated assets.
